Roland GR-50

Tone Editor

This patch editor is designed for the Roland GR-50 Guitar Synthesizer. The GR-50 uses LA (Linear Arithmetic) synthesis, the same engine as the Roland D-110, D-10, and MT-32. A Tone is the fundamental sound unit of the GR-50, composed of up to four Partials (oscillators), each with its own Wave Generator, Pitch, Filter (TVF), and Amplifier (TVA) sections.

GR-50 Operating Modes

The GR-50 has two completely independent operating modes that both draw from the same pool of 256 Tones:

Guitar mode (GK-2 hexaphonic pickup → GR-50):

  • A Patch (64 stored) is the top-level guitar preset, selected from the GR-50's front panel. Each Patch contains:
    • Patch Common — Patch name, reverb, velocity curve.
    • Patch Internal — Assigns a 1st Tone and a 2nd Tone to each of up to six strings, by Tone bank and number (e.g. a27, b09). Also controls per-string sensitivity and mixing.
    • Patch External — Controls external MIDI Branch settings (MIDI channel, mode, etc.).

Multi-Timbre MIDI mode (external MIDI controller → MIDI IN):

  • The GR-50 acts as a conventional multi-timbral sound module with two Synthesizer Parts (Part 1, Part 2) and a Rhythm Part.
  • A Timbre is assigned to each Synthesizer Part. The GR-50 stores 256 Timbres (Internal Group A: I-A1–I-A64, Internal Group B: I-B1–I-B64, plus 128 more on an optional memory card). Each Timbre contains a Tone reference plus performance parameters: Key Shift, Fine Tune, Bender Range, Assign Mode, and Reverb Switch.
  • Sending a MIDI Program Change to a Part selects one of the 256 Timbres for that Part, which in turn determines which Tone plays.

Both modes reference the same 256 Tones: 128 Preset ROM tones (Preset A: a01–a64, Preset B: b01–b64), 64 writable Internal/Card tones (i01–i64), and 64 Preset Rhythm tones (r01–r64).

GR-50 Layers at a Glance

  • A Patch is a guitar preset: it references Tones by bank and number for each string.
  • A Tone (what this editor edits) is an LA synthesis voice — up to four Partials — exactly the same as a D-110 Tone.
  • A Timbre (not edited here) is a Multi-Timbre MIDI keyboard concept: a stored combination of a Tone reference plus performance parameters, used when playing the GR-50 from an external MIDI controller. Timbres are not guitar per-string settings.

The eight tone temp slots accessible here are labelled P1–P8 by the GR-50's PG-10 programmer and correspond to:

  • P1 = String 1, 1st Tone
  • P2 = String 1, 2nd Tone
  • P3 = String 2, 1st Tone
  • P4 = String 2, 2nd Tone
  • P5 = String 3, 1st Tone
  • P6 = String 3, 2nd Tone
  • P7 = String 4, 1st Tone
  • P8 = String 4, 2nd Tone


Communicating with Edisyn

Set the Synth ID to match the Exclusive Unit Number in the GR-50's System Setup (the default is 17). The GR-50 uses Model ID 0x16, the same as the D-110. Make sure Memory Protect is OFF in the System Setup before attempting to write patches.

By default, Edisyn communicates with String 1 / 1st Tone (P1). You can change this via the GR-50 menu to target a different tone slot.

Requesting a Tone (Request Patch): When you use Edisyn's Request Patch command, you specify a Tone Bank (Preset A, Preset B, Internal/Card, or Rhythm) and a Tone Number (1–64). Edisyn loads that Tone directly into the GR-50's temp memory and reads it back — this is a Tone bank navigation, not a Timbre or Patch navigation. For example, requesting Preset A, Tone 27 loads the tone named ftRhodes from the GR-50's ROM.

Finding a Tone by name on the GR-50 hardware: The GR-50's Play mode display shows Patch names (e.g. "Pedal Steel"), not Tone names. To browse or verify individual Tone names on the unit, press INT to enter Internal edit, then navigate to Tone Edit mode and step through the bank you want. For example, Preset A Tone 27 (ftRhodes) is found under Preset A in Tone Edit, not under any Patch name.

About the GR-50 Menu

  • This editor has two layouts: a standard layout (one partial per tab) and an Alternate Layout (grouped by section across all four partials). Select the layout from the GR-50 menu; the choice takes effect the next time you open an editor window.
  • Use Edit Tone Slot: String N, N Tone (PN) to choose which of the eight tone temp slots you are editing and requesting. P1 (String 1 / 1st Tone) is the default.


Differences from the D-110 Tone Editor

  • WG Pitch Key Follow on the GR-50 is extended from 17 values (0–16) to 19 values (0–18), adding key follow values 3 and 4 beyond the D-110's maximum of 2.
  • The GR-50 has four Tone banks: Preset A (a), Preset B (b), Internal/Card (i), Rhythm (r). Inserting a memory card replaces the Internal bank; only this bank is writable.
  • The GR-50 SysEx uses the same model ID (0x16) and address map as the D-110, so Tone SysEx files produced by D-110 editors are generally compatible.


Tone Banks

  • Preset A (a) — Factory preset bank A (ROM, read-only), 64 tones.
  • Preset B (b) — Factory preset bank B (ROM, read-only), 64 tones.
  • Internal/Card (i) — User RAM or inserted memory card (writable), 64 tones.
  • Rhythm (r) — Factory rhythm tones (ROM, read-only).


Gotchas

  • The GR-50 operates primarily in a guitar-specific way: MIDI notes and pitch come from the GK-2 hexaphonic pickup rather than a keyboard. When testing tones via MIDI, send notes to the GR-50's Control Channel and ensure a Branch's MIDI Mode is set correctly in the Patch settings.
  • The PCM wave list shown in this editor is based on the Roland D-110/D-10 wave set, which shares significant overlap with the GR-50. Some wave names may differ on your unit.
  • The 256 Timbres shown on page 42 of the GR-50 manual are a Multi-Timbre MIDI keyboard feature — they are not the same as guitar Patches, and this editor does not navigate by Timbre number. If you want to edit the Tone that a specific Timbre references, look up the Tone bank and number stored in that Timbre (using the GR-50's Timbre Edit mode), then request that Tone directly in Edisyn.
